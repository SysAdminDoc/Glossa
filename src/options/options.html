Language models

Each model is downloaded once from Mozilla's catalog, checked against its published hash, and kept on this device. Nothing else is ever sent or received.

Fetch the catalog and model files from a server you run instead of from Mozilla. Build one with tools/mirror-models.mjs from the source archive and serve it over HTTPS. Glossa still checks every file against the hashes in the mirror's catalog, so only use a mirror you trust.

Privacy

  • Translation runs inside your browser using the Bergamot engine that Firefox uses. Page text never leaves this device.
  • The extension has no permission to read websites on its own. It only touches a page when you ask it to.
  • Network access is limited to three Mozilla-operated locations, used only to fetch the model catalog and model files: firefox.settings.services.mozilla.com, firefox-settings-attachments.cdn.mozilla.net, and Mozilla's model bucket at storage.googleapis.com/moz-fx-translations-data--303e-prod-translations-data. Every file is checked against the hash Mozilla publishes before it is used.
  • No account, no telemetry, no analytics, no crash reporting.
